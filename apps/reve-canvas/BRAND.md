# Brand — Reve Canvas (workstream C, branch `wt/brand`)

The internal name **"Reve Canvas"** cannot ship: it collides with the upstream model
vendor's name (trademark risk). Below are five candidate product names for an
architect-facing, **layer-based AI editing canvas** — a tool where a render is read
into editable object layers and any material can be swapped without re-rendering the
world. Names are evaluated for *plausible* `.com` availability and obvious big-name
collision (reasoning only; no web access).

## Name candidates

1. **Strata** — Latin for "layers / beds". Evokes geological strata and architectural
   layering; short, ownable, no famous collision. *Risk:* a few small SaaS/agency uses,
   but the domain niche (architecture material editing) is open.
2. **Lumenfold** — "lumen" (light/space) + "fold" (layers folding over a scene). Invented
   compound, so near-zero collision risk; slightly longer to say.
3. **Plyhouse** — "ply" (laminated layers) + "house" (architecture). Playful, memorable,
   clearly architect-facing. *Risk:* shares the "house" root with some real-estate tools,
   but not a known brand.
4. **Marl** — a sedimentary clay/stone layer in geology; one syllable, premium, tactile.
   *Risk:* also a small place-name and a few minor products, not a dominant brand.
5. **Keystone** — the central, load-bearing arch stone; metaphor for the layer that holds
   a design together. *Risk:* **rejected** — already a crowded name (Keystone pipeline,
   Keystone hardware, multiple software products).

## Chosen name: **Strata**

**Strata** is the strongest pick for three reasons. First, it is the single most
evocative word for the product's core idea — a render decomposed into stacked,
editable architectural layers — so the name teaches the UI without explanation. Second,
it reads as a serious, premium, architect-facing tool (Linear/Arc territory) rather than
a consumer toy, which matches the editorial, dark, technical polish we are after. Third,
it is a short, ownable, collision-light root that leaves clean room for product lines
(Strata Layers, Strata Trails) as auth and versioning land in later phases.
