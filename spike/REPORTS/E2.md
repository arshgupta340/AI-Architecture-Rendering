## The reframed criterion (feeds master plan)

"Geometry preservation" for this product = **mask registration**: the host's ground-truth masks must land on the render's pixels. i2i models (NB Pro, FLUX.2 Edit) reframe at will — pretty, but they break the pixel contract; per-edit misalignment would smear materials across element boundaries. Depth ControlNet pins the camera. **Only the plugin tier can supply a true z-buffer** — this is now the third stage where plugin data beats inference (after tag and segment).

## Setup learnings

- fal queue API: submit `https://queue.fal.run/<model>`, poll `status_url`; data-URI images accepted; `guidance_scale ≤ 20` on canny; **always pass explicit `image_size`** (default 1024×768 silently changes aspect → first depth run was unusable).
- Rhino depth prep: percentile-stretch the hit range, zero the no-hit background, σ≈1.2 blur (matches the monocular-trained conditioning distribution per research).
- `flux-pro/v1/canny` exists in fal's catalog but its queue never starts; if canny conditioning is needed, try `flux-general`'s `controlnets` or compute-canny + depth in one multi-ControlNet call.
