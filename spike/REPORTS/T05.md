## What was done

Added two new renderer modules under `spike/renderers/`, each subclassing
`Renderer` from `base.py` and following the T04 conventions: credentials
read from `os.environ` at call time, `requests` imported lazily inside
`render()`, no network at module import.

`magnific.py` implements `MagnificMysticRenderer` against Magnific's
Mystic endpoint. Magnific is a submit-then-poll API similar to BFL:
`POST https://api.magnific.ai/v1/mystic` returns `{"id": ..., "status":
"queued"}`, then `GET /v1/mystic/<id>` is polled (2 s interval, 180 s
timeout) until `status == "succeeded"`, at which point `output[0]` is a
signed URL the helper downloads. Provider knobs forwarded via `**kwargs`:
`creativity`, `hdr`, `resemblance`, `fractality`, `engine`, `style`,
`output_format`, `aspect_ratio`. Auth is `Authorization: Bearer
<MAGNIFIC_API_KEY>`.

`recraft.py` implements `RecraftV3Renderer` against Recraft's native
`https://external.api.recraft.ai/v1/images/imageToImage`. Recraft is
synchronous (no polling), accepts `multipart/form-data` with the source
PNG as the `image` file field and JSON-ish form fields `prompt`,
`strength`, `model=recraftv3`, `response_format`. The handler parses
`data[0]` and returns bytes from either `b64_json` (decoded) or `url`
(fetched). `seed` maps to `random_seed`; `style`, `substyle`, `n`,
`negative_prompt` pass through via `**kwargs`.

## Surprises / notes for the human

- Magnific Mystic pricing is set at $0.10/image as a working placeholder
  (Magnific's listed Mystic credit cost is in that ballpark). Tighten
  during the morning audit.
- Recraft V3 price set at $0.04/image per their public credit pricing.
- Recraft uses `multipart/form-data`, not JSON — different from BFL and
  Magnific. T11's `respx` test will need `MockRouter` matching on
  `Content-Type: multipart/form-data` for Recraft.
- Magnific's submit response field name is uncertain across docs versions
  (`poll_url` vs `status_url`); the code accepts either and falls back to
  `/v1/mystic/<id>` if neither is present.
- Both renderers honor `seed` (Magnific as `seed`, Recraft as
  `random_seed`) so bake-off determinism testing will work once API keys
  are added.
