# E4 — Vision-Banana-style segmentation probe (public Nano Banana Pro)

- **Task:** Measure how close *prompting* the public base model (`nano-banana-pro-preview`) gets to Vision Banana's color-coded segmentation — scored with real IoU against E1's host-extracted ground truth (same frame).
- **Status:** **Decisive negative.** Semantically coherent, geometrically useless. Prompting does not substitute for the instruction tuning.
- **Cost:** $0.13 (1 image call). Running ledger total: $1.02.
- **Date:** 2026-06-12

## Result

| class | GT px | pred px | IoU | recall |
|---|---|---|---|---|
| wall | 8,630 | 46,970 | 0.023 | 0.147 |
| window_glass | 3,739 | 26,611 | 0.024 | 0.191 |
| mullion | 3,666 | 9,375 | **0.003** | 0.009 |
| door | 19 | 6,580 | 0.0 | 0.0 |

## Reading

- The output *looks* like a segmentation map and is semantically right (buildings red w/ blue glazing + yellow mullion grids, ground green, context cyan). The model understands the scene.
- But it **redraws the geometry**: buildings shifted/rescaled, mullion grids painted at invented positions, 2D plan linework on the ground misread as building masses, output at a different resolution (1545×672 vs 1515×659). Masks cannot be used for editing.
- Caveat: our GT is layer-derived (tower masses = "other"), which inflates wall over-prediction — but the alignment failure is independent of that and fatal on its own.

## Implications

1. **Veras's Vision Banana advantage is the tuning, not the base model.** We cannot replicate Smart Selection by prompting; the public model's generative drift is structural (the paper's own contribution is fixing exactly this).
2. **Tier-2 fallback must be discriminative** (Florence-2/Grounding-DINO → SAM-family) — E5 decides.
3. **The plugin tier's moat grows**: ground truth (E1: 93.1% exact, mullions per-instance) vs best prompted-generative (IoU 0.003 on mullions) is a ~300× quality gap on the hardest class.
4. Watch the Gemini API changelog for a productized Vision Banana endpoint; if it ships with pixel-aligned output, re-run this probe ($0.13).
