## What was done

Three pre-conditions needed fixing before the live call could succeed:

### Fix 1: `modal.Function.lookup` → `modal.Function.from_name`

Commit: `8f960de` (`[T17] fix modal.Function.lookup → from_name (removed in modal 1.4.x)`)

### Fix 2: `spike.schemas` not importable inside Modal container

`tag_regions` in `modal_app.py` used `from spike.schemas import Region, TagRegionsResponse` but the container image doesn't have pydantic and the `spike/` package isn't mounted. Rewrote `tag_regions` to avoid the import entirely: it now returns raw JSON text from Gemini, and the local caller validates it with pydantic. Modal redeployed.

### Fix 3: Gemini returns a bare list `[...]` not `{"regions": [...]}`

When `response_schema` is removed (as part of fix 2), Gemini returns a bare JSON array. Updated `_call_live()` in `test_vlm_tagging.py` to detect a bare list and wrap it in `{"regions": [...]}` before pydantic validation.
