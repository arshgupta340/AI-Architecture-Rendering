## What was done

Wrote `spike/run_b2_variants.py`. The four B2 variants are each modelled as a `Variant` dataclass holding one or more `VariantCall` records that fully describe what would be sent to `render_from_model_view` on Modal: the resolved `image_path` (with possible resize for `higher_res`), pixel dimensions, mime type, style prompt, and `extra_constraints` string. Builder functions are pure / no-network; the live runner is only reached behind `--live`, and the `modal` import is lazy so dry-run works without Modal CLI auth.

The constraint strings are derived directly from the spike-2 failure pattern called out in the plan (right-facade window invention, wrap-around corners, fabricated mullions). `multi_region_annotated` layers per-facade callouts on top of the tightened constraints. `multi_pass` records two NB calls plus an aux Gemini-3-Pro tagging step; the second call's `extra_constraints` note explicitly references that pass-1 counts will be substituted in before sending.

Defensive checks: missing input file -> exit 2; `--live` without `GOOGLE_API_KEY` -> exit 2; non-bytes Modal return -> RuntimeError. The unicode right-arrow `→` was replaced with `->` after a Windows cp1252 console encoding crash during the first dry-run; em-dash and ellipsis remained (cp1252 has them, no crash).

## Surprises / notes for the human

- The unicode right-arrow killed dry-run on the Windows console (cp1252). Replaced with `->`. Em-dashes and ellipses survive because cp1252 has them, but they will look ugly on consoles using strict ASCII. If you want pure ASCII output, do a global replace of `—` and `…` in this file.
- `multi_pass` records the planned shape but does NOT yet wire pass-1 output back into pass-2 constraints — that requires the Gemini-3-Pro tagging function (T13/T14) to land first. The dataclass already has a slot for it (note text references "(counts pinned by pass-1 tagger - see aux_calls)").
- `higher_res` writes the resized PNG only in live mode, at `<out_dir>/<stem>__1920.png`. Dry-run shows the intended path but does not touch disk.
- Cost estimate printed in live mode is naive ($0.04 per NB call); the multi-pass Gemini tag call is not added to the estimate. Tighten this once T17 gives a real per-call number.
