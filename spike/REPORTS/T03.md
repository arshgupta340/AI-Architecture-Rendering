## What was done

Created `spike/renderers/nano_banana.py` exporting `NanoBananaProRenderer`,
a thin adapter that calls the existing `render_from_model_view` Modal
function via `modal.Function.lookup("arch-rendering-spike", ...)`. The
`modal` import and the lookup happen only inside `render()`, so importing
the module does not require Modal CLI auth or any network access. The
renderer is env-gated on `GOOGLE_API_KEY` (matching the Modal Secret the
underlying function reads), and forwards the optional `mime_type` and
`extra_constraints` kwargs through to the Modal function. Class metadata
(`name`, `provider`, `cost_per_call_usd=0.039`, `env_var`) matches the
`Renderer` base contract so the bake-off scorer can consume it uniformly.
