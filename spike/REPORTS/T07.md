## What was done
Wrote `spike/scoring.py` with three pure-CV scoring helpers that the B3 driver in T08 will use to compare every renderer's output against the source model-view screenshot. `silhouette_iou` derives binary foreground masks via Canny + corner-seeded flood-fill (edges dilated 1px so the flood can't escape through Canny gaps) and returns the IoU. `edge_density_delta` returns `count(canny(b)) / count(canny(a))` over either the full image or an optional `(x, y, w, h)` crop, so per-facade fidelity can be scored without sky pixels dominating the ratio. `count_windows` is the env-gated stub T08 will call — it validates input, raises `RuntimeError("GOOGLE_API_KEY not set")` when the key is missing, and otherwise raises `NotImplementedError` pointing at T14 (the `tag_regions` Modal function) as the proper integration point. No top-level network imports, no provider SDK pulled in.

Canny reuse: `extract_edges` from `run_b1_baseline.py` is imported lazily inside a `try/except`; if the import path ever breaks (file moves, package restructure) a `_canny` fallback with the same 60/180 thresholds kicks in so scoring still works in tests.

## Surprises / notes for the human
- The TASKS.md row mentions reusing `overlay_canny_edges` from `run_b1_baseline.py`, but that file actually has `extract_edges` (Canny only) and `make_overlay` (red-overlay compositing). I deferred to the plan's intent — Canny reuse — and wired up `extract_edges`. The overlay function isn't needed inside `scoring.py`; T08's grid builder is where overlays should live.
- `edge_density_delta` returns a raw ratio rather than a clamped 0..1 score. The B3 driver should pass it through `1 - abs(1 - ratio)` (or similar) when populating the rubric column; I didn't clamp here because the raw ratio is the more useful debugging signal (a renderer that doubled the edge count is a very different failure than one that erased half).
- The silhouette flood-fill assumes the four corners are background. That's true for every model-view export I've seen (uniform sky / page background), but it'll mis-score a render that legitimately fills a corner with building mass. If the B3 driver ever feeds in screenshots where the building reaches the edge of the frame, switch to a learned saliency mask or accept the noise.
- `count_windows` raises `NotImplementedError` rather than returning a sentinel. T08 must catch this and write `'n/a'` to the scores CSV — otherwise the driver will crash on any machine without `GOOGLE_API_KEY`.
